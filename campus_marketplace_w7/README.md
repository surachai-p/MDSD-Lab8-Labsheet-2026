## Gemini AI product suggestions

Create an API key in Google AI Studio, then provide it at launch:

```powershell
flutter run --dart-define=GEMINI_API_KEY=YOUR_API_KEY
```

The key is not stored in the source code. A key embedded in a client app can
still be extracted from the built app, so use a backend proxy and restrict the
key for production use.
